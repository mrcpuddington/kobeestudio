# Kobee Studio 1.5.21

Existing artwork can be edited on Windows with KiCad 10.0.6 when KiCad stores
an equivalent polygon with fewer vertices. Kobee Studio verifies the replacement
before removing the original. If the geometry changes, it keeps the original
and reports which check failed.

Thanks to Lucas Pfennig (@mrred2k) for identifying KiCad's removal of collinear
vertices, contributing the fix and confirming that a single Undo restored the
original artwork on Windows. [PR #36](https://github.com/mrcpuddington/kobeestudio/pull/36)
