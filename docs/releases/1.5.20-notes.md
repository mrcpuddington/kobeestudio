# Kobee Studio 1.5.20

This KiCad 10 IPC update expands the artwork tools and tightens the editor's
preview, placement and dialog workflows.

- Activate system fonts or install Google Fonts, preview individual faces,
  retain their licences and reuse installed faces offline.
- Import reusable SVG artwork and variants, convert PNGs with a tracing preview,
  and manage personal and project libraries.
- Use nine placement anchors, independent underline/overline controls, and
  optional `D_{0}` / `V^{2}` text formatting. Plain labels retain literal text
  while formatting is disabled.
- Start an editable connector overlay from a selected, evenly spaced
  single-row connector. Review the pad net names, pitch, orientation and
  pin order in the preview before placing it.
- Use round, rounded or square individual pin openings. Existing individual
  openings keep their circular shape.
- Create variable labels and designators, and use transactional board cleanup tools.
- Keep unsaved forms when library changes rebuild the editor. Invalid previews
  disable placement, compact Settings remain scrollable, and closed dialogs
  discard late background results and stop preview timers.

Complex inverted artwork now uses fewer polygons. The reproduced 32-pin case
fell from 3,912 polygons to 379, and its native position-edit stall no longer
reproduced in the local check. Hidden footprint fields now have valid text sizes.
On KiCad 10.0.0–10.0.6, close Schematic Editor before applying changes from
Kobee Studio. On Windows KiCad 10.0.6, artwork edits stage a verified replacement
in the same undo step as removal of the original. Ungroup grouped artwork
before editing on that version.

Validation includes the native wx regression suite, Linux CI and live placement,
editing, save and reload in KiCad 10.0.5 on macOS. The replacement and rollback
path was exercised on macOS with the Windows 10.0.6 condition simulated. macOS
checks also covered front and back silkscreen in GerbView and readable back-side
artwork in 3D Viewer. The original crash environments for GitHub issue #32 and
pull request #36, Windows and Linux visual checks, and visual inspection of
copper and mask plots remain open.

Install the matching `Kobee-Studio-1.5.20-pcm.zip` release asset through **Plugin
and Content Manager → Install from File**. Official-catalog availability is
separate and follows KiCad's metadata merge-request review.
