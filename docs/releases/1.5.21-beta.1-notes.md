# Kobee Studio 1.5.21 Beta 1

This beta addresses the “KiCad did not retain the replacement artwork” warning
reported when editing existing artwork in KiCad 10.0.6 on Windows 11. Kobee Studio
now accounts for duplicate polygon vertices that KiCad removes when storing the
replacement. If verification still fails, Kobee Studio keeps the original
artwork and reports which check failed.

Install `Kobee-Studio-1.5.21-pcm.zip` through **Plugin and Content Manager →
Install from File**. KiCad lists the package as version 1.5.21 with testing
status. The current stable release is 1.5.20.

Please try editing the original artwork on a copy of your board. Check that the
edit appears in place and that one Undo restores the original. If the warning
returns, share the full message and your exact KiCad version in the
[original GitHub thread](https://github.com/mrcpuddington/kobeestudio/pull/36#issuecomment-6719472797).
