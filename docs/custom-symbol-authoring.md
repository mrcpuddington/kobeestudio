# Authoring custom Kobo Studio symbols

This guide describes the first, deliberately strict Kobo Symbol SVG profile.
It is designed for predictable PCB artwork—not for accepting every SVG that a
design program can produce.

## The short version

Use an Inkscape document with a **240 × 240 px** page. This is a recommended
working canvas, not a requirement enforced by Kobo. Keep the visible symbol in
roughly the `20–220 px` area so that it has a little breathing room.

Before upload, save as **Plain SVG**. Kobo scales the artwork to the symbol
height selected in the editor; SVG pixels do not correspond directly to PCB
millimetres.

## Kobo Symbol SVG profile

For now, an imported symbol must contain only simple, filled PCB regions:

- Use closed, solid filled shapes.
- Convert every stroke to a filled path before export.
- Difference-style holes/cut-outs are supported when exported with the SVG
  `evenodd` fill rule. Do not use clipping masks, filters, gradients, embedded
  images, text, external links, scripts, or fonts.
- Do not use open paths or `fill="none"` artwork.
- Keep every feature visually clear at the smallest intended symbol height.
- Use the same canvas, centre, and approximate visual bounds for `default` and
  `rounded` variants of one symbol family.

The upload validator intentionally rejects unsupported SVG rather than risking
silently incorrect copper or silkscreen artwork.

## Recommended visual weight

For a normal symbol that occupies approximately `200 px` of a `240 × 240 px`
canvas, start with a **28 px stroke** while designing. After converting that
stroke to a path, it produces a good all-purpose visual weight for small
silkscreen symbols.

This is only a starting point. The physical result is determined by:

```text
physical feature width = selected symbol height × (feature width / artwork height)
```

For example, a `28 px` feature in `200 px`-high artwork becomes about
`0.17 mm` when the user selects a `1.2 mm` symbol height. If the symbol will
commonly be used smaller than that, make the feature heavier or simplify it.

## Inkscape setup

1. Open **File → Document Properties** (`Shift+Ctrl/Cmd+D`).
2. Set the page width and height to `240 px`.
3. Press `5` to zoom the page to fill the Inkscape window—there is no need to
   design at a tiny on-screen size.
4. Use a single solid fill colour. The exported colour is not meaningful to
   Kobo; the geometry is what matters.
5. Before saving, select artwork and use **Path → Object to Path**. For any
   visible outline, use **Path → Stroke to Path** first.
6. Save using **File → Save As → Plain SVG**.

## A hollow-circle / ring symbol

Use the normal Inkscape workflow:

1. Draw a filled outer circle.
2. Duplicate it, scale the duplicate down while holding `Ctrl+Shift` so it
   stays centred, and place it on top.
3. Select both circles and choose **Path → Difference** (`Ctrl/Cmd+-`).
4. Save as Plain SVG.

Kobo recognises the even-odd cut-out generated by Difference and converts it
to non-self-intersecting filled PCB regions internally. The result remains a
continuous hollow ring—there is no need for visible gaps or segmented arcs.

## Variants

Use **default** for the canonical design. Where it makes visual sense, make a
**rounded** version using the same 240 px page, centre, apparent height, and
weight. Kobo identifies variants as members of one symbol family, so switching
between them should not move or resize the label layout.

The uploader lets you choose the display name, category, scope, and variant;
it creates the internal file and ID safely. Contributors adding bundled SVGs
should follow the repository naming rule:

```text
kobeestudio/resources/symbols/<category>/<symbol_slug>--<variant>.svg
```
