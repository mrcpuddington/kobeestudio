# Kobee Studio showcase board

This is a polished visual feature index for repository screenshots. The board
includes custom labels and container shapes, stand-alone symbols, component
callouts, a component array, 2.54 mm connector overlays, QR and Code 128
generation, and front/back copper, mask and silkscreen examples.

Open kobee-studio-showcase.kicad_pcb directly in KiCad 10.

To regenerate it on macOS, run the generator with KiCad 10 bundled Python:

    /Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/3.9/bin/python3.9 \
      examples/showcase/generate_showcase.py

The renders directory contains reproducible top, angled and bottom images for
the main README.
